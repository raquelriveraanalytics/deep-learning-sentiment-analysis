# Deep Learning Sentiment Analysis

This project applies deep learning techniques to perform sentiment analysis on text data using an LSTM (Long Short-Term Memory) model.

Steps included:
- Text preprocessing (cleaning, tokenization, padding)
- Converting text into numerical sequences
- Building and training an LSTM neural network
- Evaluating model performance using accuracy

Tools used:
- Python
- TensorFlow / Keras
- Google Colab

This project demonstrates how deep learning models can capture context and improve performance compared to traditional machine learning approaches in natural language processing.
